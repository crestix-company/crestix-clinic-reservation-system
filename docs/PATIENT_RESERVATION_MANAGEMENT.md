# 患者・予約管理画面 README

## 目的
「患者・予約管理」は、本日の受付業務ではなく、過去・未来を含む予約検索、予約変更、電話問い合わせ対応、患者履歴確認を行うための管理画面です。

## 他画面との役割分担
- **本日の予約・受付**：当日の来院受付・待機・診察進行を管理
- **予約カレンダー**：時間枠・担当医ごとの予約状況と空き枠を確認
- **患者・予約管理**：日付をまたいだ予約検索、患者検索、予約変更、履歴確認

## 想定業務
1. 患者名、電話番号、Patient ID、Reservation IDから予約を検索する
2. 日付、診療メニュー、予約経路、状態で予約を絞り込む
3. 患者単位で予約履歴・受診履歴を確認する
4. 電話問い合わせ時に対象予約を特定し、変更・キャンセルを行う

## 識別子
- **Patient ID**：Crestix側で患者1人を識別するID
- **診察券番号 / EHR患者番号**：クリニック・電子カルテ側で患者を識別する番号
- **Reservation ID**：予約1件を識別するID

これらは別の識別子として扱い、相互に混同しません。

## 初診患者
初診患者の新規作成と電子カルテ側への新規登録フローは、宅保さんへの要件確認後に実装します。現段階では確定仕様として実装しません。
